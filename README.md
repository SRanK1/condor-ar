# Cóndor Andino en Realidad Aumentada (WebAR)

Página web que coloca un cóndor andino 3D animado en el espacio real desde el navegador del celular.

- `index.html`: la página (usa [model-viewer](https://modelviewer.dev), incluido localmente en `model-viewer.min.js`)
- `condor.glb`: modelo 3D con animación de vuelo circular (Android y navegador)
- `condor.usdz`: el mismo modelo para iPhone (AR Quick Look)

Android (Chrome): WebXR o Scene Viewer · iPhone (Safari): AR Quick Look.
